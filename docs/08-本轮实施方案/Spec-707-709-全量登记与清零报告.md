**领域不变量与事务边界**
- 期望侧唯一出处：行结构形状只来自 gorm 自己的解析器（`schema.Parse`，即 gorm 写入所依据的同一份知识）；导出助手只递实例，不复制形状知识；
- 产物侧唯一出处：真实迁移链执行产物（`RunMigrationsWithOptions` 建到最新 → `PRAGMA table_info`）；
- 判定规则唯一出处：仍集中在 `row_shape_guard_test.go` 顶部注释 + `compareRowShape` 一处，本票不新增第二处判定语义；
- 登记完整性：AST 扫描发现的 (包, 类型, 表) 三元组集合与登记清单（减去显式排除）**集合相等**——双向强制，计数一致由结构保证而非硬编码数字；
- 排除三硬要求：逐条理由 + 写明解除条件 + 跟进票号（`#NNN`），缺任一守护红；
- 裁定真相源：既有不匹配以领域语义裁定改哪一侧（结构体声明侧或双方言成对迁移），逐条记录在下方裁定登记表；
- 只读检查：守护本身不写数据、不进启动路径。

**成功 / 失败 / 恢复场景**
- 成功：全量登记 + 真实迁移链逐列比对零违规（或仅剩显式排除项）；
- 失败：① 新增行结构未登记 → AST 守护红；② 清单悬空 → 红；③ 登记行结构与迁移产物漂移 → 形状守护红（表/列/两侧形状齐全）；④ 排除缺三硬要求之一 → 红；⑤ `TableName()` 返回非常量字面量 → 扫描红（无法钉扎表名）；
- 恢复：修漂移侧（登记/结构体/迁移/归一化表），排除按登记的解除条件销项。

**持久化 / 并发 / 审计证据**
- 持久化：迁移链建库到当前最新版本（fresh 临时库）；若裁定需要新迁移：sqlite+versioned 成对、版本常量棘轮推进、双方言升降演练测试通过；

- 审计：N/A（无用户可见状态变更）。
