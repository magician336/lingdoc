# P2 · 图标系统（icons）

> 所属集成：`codex/ui-design-system-20261105` → 草稿 PR #6 → main。设计依据：`DESIGN-SYSTEM.md` §2.7。效果预览与「当前/精修」对照见会话小样（lingdoc-ui-demo.html，可向 owner 索取）。
> **云端施工，未经原生编译验证。**

## 范围

只改 `engine/crates/ui-egui/src/icons.rs`：

1. **Pen 原语最小扩展**：给 `Pen` 增加圆角半径参数的矩形（现有 `rect` 硬编码 1.0 半径）、圆弧方法（`undo`/`redo` 里已有手写圆弧先例，收编为 `Pen::arc`）、可选独立线帽。保持全部既有方法签名不变。
2. **全量重绘纪律**：286 个 match 分支逐一过网格——统一笔画 1.25→**1.5**、内容区留白 3–3.5、端点吸附半格（x.0/x.5）、强调色只给动作部件且每图标至多一处。
3. 文字图标（bold/italic/underline 等）保持字体方案，只校正基线与重心。

## 工作方法

- 分批施工（每批约 30 个），每批保持 `match name` 结构不变，只改绘制体；
- 不新增、不删除、不改名任何图标 key（调用方按字符串引用，改名即编译期不可见的回归）；
- 形状图标（`shape.*` 前缀分支）最后一批处理。

## 验收

- `cargo check -p wordcraft-ui-egui` 通过；
- 图标 key 集合与施工前完全一致（用 `grep -oE '"[a-z0-9_.]+"( =>| \|)'` 对比）；
- 20px 实尺寸下笔画清晰、无半像素发虚（本地截图抽查功能区）。
