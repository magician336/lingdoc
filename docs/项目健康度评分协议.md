# LingDoc 项目健康度评分协议

## 目的

本协议用于在每个 Spec 完成时、PR 合并前评估 LingDoc 的设计健康度，以及 LingDoc 与整体仓库的契合度。两次评分使用同一套权重，保留分数、证据和置信度的变化。

本协议评估的是可持续开发能力，不把代码规模、文件数量或功能完成度直接当作健康度。

## 两个评分对象

### LingDoc 系统健康度（`H_L`）

评估 LingDoc 自身是否易于理解、修改、验证和演化。取样范围以 `internal/lingdoc`、对应前端、接口契约、测试、文档和验收材料为主。

### LingDoc—仓库契合度（`F_R`）

评估 LingDoc 与整体仓库的边界、依赖、契约、文档、CI、部署和协作流程是否匹配。它不是整个 WeKnora 仓库的独立质量分数。

整体仓库评分包含自维护代码、前端、文档、CI、部署和协作流程。`third_party`、供应商代码和生成代码纳入依赖风险记录，但不把其内部设计直接计入 `H_L`。

## 评分维度与权重

每个二级指标按 0–5 评分，健康分计算为：

```text
维度得分 = Σ（二级指标权重 × 指标得分 / 5）
总分 = 六个维度得分之和
```

| 维度 | 权重 | 二级指标 |
| --- | ---: | --- |
| 复杂性控制 | 20 | 变化放大 8、认知负荷 7、特例与信息泄漏 5 |
| 模块深度与边界 | 20 | 接口成本/隐藏收益 7、信息隐藏 6、层次错位 4、耦合与透传 3 |
| 演化式设计 | 15 | 结构不同的候选方案 5、增量与回退 5、持续重构 5 |
| 战略执行 | 15 | 设计投资与债务偿还 6、路线与依赖一致性 5、变更局部性 4 |
| 一致性与显然性 | 15 | 领域术语/文档 5、契约与非显然注释 3、代码语义一致性 4、自动化约束 3 |
| 证据、反馈与恢复 | 15 | 未知发现 5、失败/权限/恢复测试 5、CI/观测/回退 5 |

对 `H_L`，指标观察 LingDoc 内部；对 `F_R`，同一指标观察 LingDoc 与宿主仓库边界处的表现。

## 五级评分锚点

- **0**：缺失，或无法提供可信证据。
- **1**：依赖个人记忆，规则高度不稳定。
- **2**：局部有效，跨模块或跨团队不一致。
- **3**：基本可用，但仍有明显人工成本或未收敛债务。
- **4**：系统化，并有自动检查、测试或固定流程。
- **5**：有持续度量、反馈、复盘和改进记录。

“未知的未知”不直接评分。它通过未知发现速度、失败诊断、可观测性、回退能力和关键假设的验证程度间接评估。

## 两个评分时点

### Spec 完成

评估设计边界、模块职责、依赖关系、领域术语、错误和恢复场景、候选方案比较以及验证计划。尚未实现的代码指标必须标记为待验证，不能按设计意图直接给满分。

### PR 合并前

重新评估真实代码、测试、失败路径、权限场景、CI、文档同步、部署集成和验收证据。记录相对 Spec 阶段的 `ΔH_L`、`ΔF_R`，并解释变化原因。

每次评分必须绑定：

- Git SHA；
- Spec 文件和版本；
- PR 编号；
- 取样范围；
- 验证命令及结果；
- 未覆盖风险。

## 置信度

- **A**：主要结论由自动化测试、CodeGraph、CI 或可复现运行结果支持。
- **B**：主要结论由代码抽样、文档、PR 证据和部分自动验证支持。
- **C**：主要依赖设计意图、个人判断或尚未验证的假设。

整体置信度不是简单平均。只要关键维度仍缺少证据，整体置信度最多为 B；多个关键维度缺少证据时标为 C。

## 健康等级

- **80–100**：健康，可持续扩展。
- **60–79**：可持续开发，但存在明确治理债务。
- **40–59**：脆弱，应先治理再扩展。
- **0–39**：高风险，需要优先恢复边界、验证和反馈能力。

任何关键维度低于 2/5 时，必须单独列为阻断风险，不能被总分掩盖。

这是按本协议正式执行前的初始估计，后续应在第一个 Spec 完成时复核：

| 分数 | 暂定值 | 置信度 | 说明 |
| --- | ---: | --- | --- |
| `H_L` LingDoc 系统健康度 | 66/100 | B | 文档和测试治理较强，但接口表面、复杂性和 Go 验证环境仍有债务 |
| `F_R` LingDoc—仓库契合度 | 69/100 | B | Spec、CI 和协作入口已有集成，但跨模块 Go 验证和真实运行证据不完整 |
| 可选仪表盘总分 `0.7H_L + 0.3F_R` | 67/100 | B | 仅用于总览，诊断必须保留前两个原始分数 |
