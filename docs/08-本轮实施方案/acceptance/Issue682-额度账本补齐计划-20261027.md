# Issue #682 本地收尾：CI 与额度账本

目标：修复 #755 的 CI 包族登记遗漏；使用现有 Workspace 事务、授权、版本化对象与审计实现项目累计额度，不另建工作流、数据库或访问权限。生产无批准策略时继续阻断。

## 实现前不变量

- 唯一账本所有者：workspacecore，持久化使用现有 Repository/Object transaction；不把正式额度放在前端或内存计数器。
- 外部提供批准策略及明确窗口起止时间；代码不猜测白名单、额度值、日/月周期或重置时间。
- 项目写锁内检查授权、策略窗口、累计占用并写入预留及审计，失败必须原子回滚。
- Run/turn ID 全项目唯一；重试不能重复计费，换窗口不能复用旧 ID 洗掉消费；同 ID 的不同请求必须冲突。
- 预留按已保存计划的最大搜索/返回量保守占用；结算记录实际累计量。没有已持久化终态证明时，不退款、不放宽剩余额度。
- 暂停保持剩余预留；进程重启从同一数据库恢复；未知结算保持占用并拒绝继续调用。
- 配额窗口不能重叠或因策略版本变化重置已有计数；新窗口保留历史对象版本。
- 生产组合根显式安装账本，缺策略 provider 时返回原有不可用状态；合成额度只出现在测试夹具。
