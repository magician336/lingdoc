这一份由执行者填写。执行器只负责算哈希、给模板和校验必填字段齐全，
**不判定文档内容**——程序库 roundtrip 不能替代这一检查。

| 字段 | 值 |
| --- | --- |

| 原始 DOCX SHA-256 | <机器填写：本轮没有拿到下载的文件> |
| 修改后文件 SHA-256 | <待填：保存后由执行器计算，或由执行者填写> |

| 检查人 | <待填> |
| 检查时间 | <待填> |

## 检查清单

- [ ] 打开下载的文件，改一处正文，保存，关闭并重新打开
- [ ] 修改保留
- [ ] 正文、标题层级、引用和基本格式仍可用
- [ ] 附录列出 review-1 原文、保留原因及内部演示标识
- [ ] 摘要 hash 与下载真实字节相等（这一条由 F01-23 的 hash_equals 机器核对）

## 本轮怎么算的

- 原始 DOCX 的 SHA-256 由执行器对本轮下载的文件计算：本轮没有拿到文件
- 修改后文件的 SHA-256：本轮没有拿到修改后的文件
- Windows 版本：10.0.26200
