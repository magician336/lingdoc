## 目的地与现状

Workspace 尚无 ContextPackagePanel 挂载。原面板已实现意图/事实分离、预览、卡片状态对齐及请求序号；不修改它或 agentContext/agentApi。沿用现有侧栏入口和 full-workflow 抽屉，不重构 Workspace。增加薄宿主 ProjectContextPackagePanel，读取当前项目版本作为预览基线，再挂载原面板。预览不创建会话、不调用模型、不写业务对象；不是“已保存的上下文包”，事实来自每次 POST agent-context。

## 真相、不变量、失败恢复

- 项目/租户/账号由 Workspace 提供；组件以完整身份为 key。项目切换先销毁旧实例，不继承卡片、事实或请求。
- 项目版本、context revision 来自 getProject 当前读回，不猜测或静默推进卡片版本。expected_version 沿用既有预览语义 0；无任务/章节就不填。
- 服务端 BuildAgentContext 拥有授权、来源可用性、选择理由、版本基线；原面板只投影该包，不按本地选择伪造事实。
- 候选摘要来自原 listEvidenceCards，预览与候选各一次请求。宿主从原客户端读回收集候选，不新增并行列表请求/轮询。
- 每次手动刷新先移除旧事实，重读项目基线，重建预览实例；保留同一身份的精确卡片引用（不改版本）。409 不自动重试；权限错误不变成空包。
- 项目读失败不挂载面板；候选读失败显示告警，原门面仍能以“状态未知”展示服务端包，不冒充成功清单。宿主异步更新有代次守护，卸载后不回填。
- 刷新/关闭/重开由用户触发，不缓存正文/包到 localStorage。无后台轮询。只读路径不改变事务/幂等/审计语义，无新增数据库或 API。
