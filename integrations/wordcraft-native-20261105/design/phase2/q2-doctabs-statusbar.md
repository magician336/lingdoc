# Q2 · 文档标签条 + 状态栏

> 集成分支：`codex/ui-phase2-20261105`。交互稿：`mock-v4.html`（文档标签条与状态栏部分）。
> **云端施工，未经原生编译验证。**

## 现状

- 文档/阅读标签与"视图、已最大化"等操作混排在一条带子上（`source_workspace.rs` / `source_workspace/tabs.rs`）；
- 状态栏在 `chrome.rs status_bar()`，P1 已做间距令牌化，但信息组织是 Word 式平铺。

## 施工点

1. **标签条纯化**：只放真文档——主文稿（可编辑，未保存时显示琥珀点）与资料阅读标签（🔒只读 + 版本 + ✕）；活动标签 2pt 品牌顶条 + 白底浮起（mock 样式）；
2. **视图操作收纳**："视图 / 已最大化"移入标签条右端「…」菜单，不与标签混排；
3. **状态栏 VS Code 化**：
   - 左侧：保存状态（● 绿已保存 / 琥珀未保存，**点击 = 保存**，走现有保存事务入口）、Go 版本、同步状态；
   - 右侧：字数、页码、语言、缩放、专注模式；
   - 每格可点击（hover `hover` 底 + 圆角），无动作的项保持 `text_dim` 不可点击外观；
4. 未保存点/保存态只消费真实保存状态（`WorkspaceSaveCoordinator` 回执），不得由动画或本地推测设置。

## 明确不做

- 不改保存事务、标签的打开/关闭/分屏协议（`source.begin`/`commit` 不动）；
- 不加新状态项；缩放与专注只接既有命令。

## 验收

- `cargo check` 通过；workspace 54/54 与浏览器回归 22+6+5 不回退；
- 标签条在只有主文稿时无残影；资料标签的只读标识与真实只读行为一致；
- 状态栏保存项点击后状态变化与回执一致（负向：保存失败时不变绿）。
