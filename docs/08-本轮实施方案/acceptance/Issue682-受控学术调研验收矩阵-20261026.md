## 已知业务输入与边界

- 尚无获批的全局期刊/会议白名单来源、规则维护人或生效数据。代码只接受注入的版本化快照；生产组合根未配置该快照，因此 Crossref 检索和候选晋级会阻断。
- 尚无项目累计搜索数、返回数、模型调用数的额度数值及重置周期，也没有生产持久化额度账本。运行和研究助手模型调用均要求预算端口；生产未配置端口时拒绝调用。每任务内的上限不代替累计配额。
- Crossref 适配器只取得书目元数据，不抓取原文、摘要或定位信息。此类记录只能作为 `metadata_only` 候选，不能生成定位型证据卡或进入正式证据。
- 本矩阵中标为 PASS 的外部学术来源情形使用合成策略快照、合成 HTTP 响应或本地 SQLite；这些合成结果不是正式白名单或生产配额验收。另有本地真实浏览器和 Docker 服务证据，范围仅为 fail-closed 与重启读回，见新报告。
