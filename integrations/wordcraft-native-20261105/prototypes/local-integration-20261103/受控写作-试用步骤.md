# 受控写作第一版试用

本地第一版已通过完整真实浏览器验收，等待 gong 实际体验。入口：<http://localhost:7211/>（也可 <http://127.0.0.1:7211/>）。独立数据在 `runtime/controlled-trial`，使用虚构科研材料；旧7210项目不迁移、不覆盖。验证明细见 `V1-IMPLEMENTATION.md`。

## 先试一处修改

1. 点击“继续写作”。在 WordCraft 中选中“样本选择”段落的一部分或整段，不跨段。
2. 打开右侧“助手”，点“使用当前正文选区”。检查列出的允许修改文字。
3. 建议先输入“保留四个社区与问卷访谈安排，将全市结论收窄为已联系社区的受访者，不新增事实或数字”。勾选联系记录v1；按需勾选当前人工意见。确认可发送内容后生成候选。
4. 生成期间可查看正文，候选本身不写入文稿。比较修改前与候选；需要时点“在原文中选亮修改位置”。
5. 拒绝不改变正文；接受只写入选定范围。检查原生正文，再点“保存并核对版本”。
6. 可以用“撤销此次修改”检查撤销；若其后已有其他编辑，受控撤销会拒绝，避免误撤用户后续内容。正常原生撤销重做仍保留。
7. 完成保存后刷新或重新打开：核对正文内容；历史候选保留，但旧会话选区不可再用于执行。

## 再试资料变化与人工判断

1. 在资料面板登记v2更新，查看四社区变为两社区的原文。正文不会自动变化。
2. 打开“审阅与交付”，查看明确关联的样本范围与招募进度。
3. 选择修改、无需调整或暂缓；无需调整需要理由。若修改，返回正文按前述流程处理。
4. 修改并保存后，在对应条目填写实际处理说明、关联保存版本。这里记录的是用户确认，不宣称系统自动判断研究结论正确。

## 需要留意

- AI读取范围与修改范围分别显示。资料模型使用许可会登记在项目中；后续请求仍需主动选择上下文。
- 候选期间正文、资料或人工意见变化时，旧候选不能直接覆盖新内容。
- 本版为原生选区定位与旁侧候选对照，未实现原生逐字修订覆盖层；快捷意图为预设选项，可自由补充。
- 支持同一普通段落文字；域、复杂修订、对象、跨段和跨单元格范围明确拒绝。图表不在本版范围。
- 模型连接失败时显示真实错误，不会回退到固定演示回复。
- 本轮模型曾出现上游503，随后恢复并通过真实验收；如再次失败，正文不变，可稍后明确重试。不要把等待时继续修改后的旧候选直接写回。
