# G2 生成证据和模板契约

研究结果、主张和模型候选均保留待核性质。证据卡的人工确认仅表示来源片段、位置、适用范围和当前版本已经人工核对，不表示科学结论已经成立。

生成请求可选 `evidence_card_refs: [{ "id": "card-id", "version": 2 }]`。选卡时不需要再次选资产；可省略 `asset_ids` 或传空数组，服务器从正式确认卡的实际来源派生资产。若两者同时提供，资产必须与卡片实际来源完全一致。没有选卡时继续使用既有 HybridSearch 来源路径，该路径不会声称证据已经人工确认。未知字段仍拒绝，ID/正版本、去重和最多 20 个引用在服务器校验。

局部改写请求及候选结果也支持同样的可选引用。它只使用选卡实际来源；选区中已有、却不在选卡来源内的引用会拒绝。卡片引用不授予资料权限：当前项目、KB 授权、来源版本、原文位置、内容哈希、用途和模型许可全部同时检查。

服务器把证据引用写入不可变队列输入和 Candidate Basis；使用项目当前实际模板副本定义，固定 template_copy_id、template_copy_version、template_copy_content_hash、独立 ruleset_hash 和 context_revision。重放使用原队列输入重新检查后才重新入队；执行前、模型返回后和候选查看时继续检查。卡片、主张、来源、模型许可或模板依据变化会阻止旧结果继续成为可采纳候选。最终候选采纳仍需采纳域再校验。

局部改写的服务器行保存 evidence_card_refs_json 和 template_basis_json，不让客户端写模板或来源正文。模型继续接收原有选区和授权来源，只新增版本/哈希审计元数据；未增加完整模板定义或项目条件外发。创建、模型返回、查看、重放及采纳前均重读当前依据。

正式生成发起和同键重放、局部改写创建/采纳，以及 G2 人工确认动作拒绝 API key 和 API/embed principal。异步生成只接受已经通过人工身份入口的请求；队列只保存租户、用户、角色等非秘密投影，由服务器执行时复核当前角色和章节写权限。旧队列没有 human_initiated 服务器标记会在模型调用前失败，需要真人重新发起。这一轮没有提供机器身份异步生成功能。

本轮新增用例使用真实 SQLite 存储及明确 fake 模型/source adapter；它们不构成真实模型、科学核实或浏览器端到端验收。真实模型调用统一由 ROOT 调度。

当前卡片 SupportType、Scope、Limitations 和已授权 SourceIDs 已作为 typed EvidenceConstraints 写入服务器不可变输入；局部改写另保存 evidence_constraints_json。执行前后、查看、重放和采纳前均与当前已选卡逐字段比较。**这些新增卡片元数据尚未获自动审批允许外发，模型 payload 接线未完成。** 模型现在只补充不含项目数据的通用语义守则。不能宣称模型已经理解该卡片的具体反对性质或适用限制；采纳前仍须人工对照卡片核对。两次拒绝的编辑没有执行，也没有真实模型请求。
