# G3 缺口收口：当前状态

> **这份文件是什么**：G3 缺口收口线（G1–G7 里的 G3）的**当前状态入口**。它是**活文档** —— 每轮收口更新同一份，不按日期另建快照。
>
> **它不是什么**：它不是落证。每一份判定与证据都在 `docs/08-本轮实施方案/` 的验证报告与证据 JSON 里，各自记着自己的落证 head。本文只做三件事：说清「现在是什么状态」、指到「证据在哪」、指到「该读哪份文档」。
>
> **代号口径**：G1–G7 是团队的**文档层级叫法**，用于组织规格、验收与交接说明；代码与用户可见文案里不带开发代号。

**基线的含义**：本文档同步时的 `origin/main` 为 `c333feec`（PR #378）。
「基线」回答的是「读者读本文档时，main 长什么样」；**落证 head** 回答的是「那份证据跑在哪次提交上」。两者不是一回事 —— 每份证据的落证 head 记在证据文件自己的 `head` 字段里，本文不复述，以免被误当成当前 head 的结论。
