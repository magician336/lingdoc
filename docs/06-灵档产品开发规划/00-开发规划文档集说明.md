# 灵档产品开发规划文档集

本目录保留完整产品设计，同时区分本轮实施与后续规划。开工先读[本轮范围](../08-本轮实施方案/01-范围与任务流程.md)和[待领取任务池](../TEAM_DEVELOPMENT_TASKS.md)。

## 本轮使用规则

- 任务按当前 T01–T16 领取，人员在领取时确定，不按个人特长或 A/B/C 领域预分整包工作。v0.4 的独立前端 T15–T18 已并入 T07–T14，原 T19/T20 分别重编号为当前 T15/T16。
- 本轮范围、HTTP、行为规则和任务依赖分别由[文档入口](../README.md)列出的文件维护，不以长线设计整体覆盖本轮任务。
- 架构边界约束数据写入和接口，不形成某位同学对整个领域的永久所有权。
- 当前代码能力须实测；目标、样例和验收条件均不表示功能已实现。
