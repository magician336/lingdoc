# G2 依据引用、回看与最小复核：实现交接

基线：`main` / `ab5fe3d`；实现分支：`codex/g2-development-plan`。

本次实现把用途/限制备注写入不可变章节版本，读取章节时通过既有 `SourcePolicy` 复核当前来源，并把当前状态与敏感内容清除规则接到工作区和交付冻结输入。用途/限制跟随章节版本进入交付快照；旧版本仍保留，新的章节版本仍需重新确认。
