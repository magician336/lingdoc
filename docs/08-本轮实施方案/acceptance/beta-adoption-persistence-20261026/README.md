## 5. 脱敏说明（为什么这里看不到正文）

按仓库的证据脱敏规则（`scripts/ci/test_lingdoc_beta_evidence.py` 的 `find_leaks`），
本目录的副本做了如下处理，**原始文件未删、仍在仓外完整现场**：

- 绝对路径 → `<abs-path-redacted>`；
- 令牌形状 / 口令字段 → 无（本次采集不含）；
- **正文与响应体片段**（`body_markdown`、章节存储的 `response_json`、错误 `message`）→ 替换为
  `{"sha256": …, "utf8_length": …}`。
  替换是**无损可比对**的：正文在采纳响应、独立读回、数据库物理行三处的 sha256 相同，
  「三者逐字一致」这一断言因此仍可被独立复核，而仓库里不留原文响应体。

复核者可用同一算法重算：字段值 → `sha256(utf-8)`，与本目录中三处哈希比对。
