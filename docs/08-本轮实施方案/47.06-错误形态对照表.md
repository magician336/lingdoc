### 口径说明

- 第 1、2 项：规则集存储面的 `state_conflict` 拆入 409 `invalid_state` 与 409 `version_conflict`，对外错误码 `state_conflict` 退役。
- 第 3 项：工作区核心把「规则集未发布」翻译成失败时改用具名场景类型 `workspacecore.ErrRuleSetStateNotAllowed`，答 409 `invalid_state`。
- 第 4 项：治理面 5xx 的 `retryable` 从 false 改为 true，含兜底 500。
- 第 5 项：候选采纳面除依赖不可用外的 5xx 的 `retryable` 从 false 改为 true，含兜底 500。
- 第 6 项：治理面与 G2 面的错误信封去掉 `"details": null`。G2 面不在计划「少数口径变更清单」的逐条记录里，但不可变契约第 5 条要求所有面答同一字段集，G2 面也不是合法携带 details 的两条路径之一，故一并收口。
- 第 7 项：生成面 `ErrStaleInput` 从 409 + `internal_error` 改为 409 `stale_input`「候选稿或快照基于旧输入。」。
