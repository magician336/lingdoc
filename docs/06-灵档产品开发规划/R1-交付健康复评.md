## 优先治理顺序

1. **材料观察跨宿主边界 → 诊断树实现细节泄漏 → 在 #599 状态契约稳定后，以权威材料观察投影替换 spans 细节 → 降低状态规则变化时消费者同步成本 → 真实当前索引、合成占位、失败/未知/旧 attempt 和检索可用性守护不得放宽。** 不在 R1 中接管 #599。
2. **Workspace 资料入口 → 两组资料库整形与绑定入口并存 → 后续合并为共享材料选择/观察端口 → 减少用户认知与平台 envelope 重复 → 保留既有按名称绑定、正文引用和新上传全链回归。** 本轮不顺手删旧能力。
3. **平台重解析 → 清理和任务入队无版本前置承诺 → 由拥有者补幂等/并发恢复契约后才开放项目内重试 → 避免用户靠反复重传恢复 → 并发两客户端、响应丢失及已有引用不误伤。** 当前只显示原因和下一步，重新读取不产生写入。
