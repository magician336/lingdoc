# LingDoc 开发文档

LingDoc 是构建在 WeKnora 之上的科研项目写作与交付工作台。本轮先完成“项目→资料→候选稿→人工编辑与确认→可编辑文件”的真实流程。

## 开工先读

1. [本轮范围与任务流程](08-本轮实施方案/01-范围与任务流程.md)：交付什么、先验证什么、哪些暂缓。
2. [待领取任务池](TEAM_DEVELOPMENT_TASKS.md)：按任务领取，负责人和评审人在领取时确定。
3. [协作与代码边界](06-灵档产品开发规划/05-团队分工与代码边界.md)：接口交接、Mock、PR 和冲突处理。
4. [接口与 Mock 约定](08-本轮实施方案/02-接口与Mock约定.md)：状态、版本、采纳、确认、冻结和恢复语义。

**不按个人特长预分任务，也不把 A/B/C 领域打包给某个人。** T01–T20 只表示工作项；领域边界限定数据和接口的职责，不限定谁来实现。

## 文档维护

本轮协作以仓库中合并后的文档为共同版本。外部笔记可继续整理，但影响范围、接口或任务的变更先通过文档 PR 对齐，避免两套版本分别指导开发。

当前契约是待实现方案。静态校验覆盖示例结构和关键不变量，真实服务、数据库、模型及 DOCX 仍需任务中的验收。参见[方案文件与校验说明](08-本轮实施方案/README.md)。
