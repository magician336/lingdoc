## 4. 仍须守住的首轮门槛

- 未授权资料/其他项目不得读取或进入模型；撤权后的受限读取/下载继续拒绝。
- 旧版本写入明确冲突，不能静默覆盖；输入保留，身份/项目切换不回填旧结果。
- AI只产生待人工决定的候选；真实资料是否可外发需单独确认，现有合成授权不能覆盖新资料。
- 无依据的数字/结论保留待核；来源标记不自动代表来源支撑，人工处置保留理由。
- 检查、稳定化、快照、导出绑定对应版本；实际下载文件与记录一致，可在Word打开编辑保存重开。
- 样本不足保持NOT READY，不伪造科研结果、真人样本或扩大决定。

试写若发现越权/泄漏、正文丢失/被覆盖、错项目文件或文件打不开，作为本轮问题回原PR处理；不能用“延期”绕过这些门槛。相关失败保留原始结果，不以平均通过率掩盖。
