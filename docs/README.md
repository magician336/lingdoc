# LingDoc 开发文档

本目录收录**灵档（LingDoc）** 的产品与开发文档。灵档是构建在 WeKnora 之上的科研项目申报工作台：WeKnora 提供知识与 Agent 数据平面，灵档在其上交付面向研究项目的产品层与领域层，RuoYi 作为 root 级运营控制平面。

## 基线优先级

发生冲突时按此顺序裁决：

1. 当前 WeKnora 仓库与 [`DEVELOPMENT_PLAN.md`](DEVELOPMENT_PLAN.md) —— 定义平台边界
2. [`PROJECT_TOP_LEVEL_DEVELOPMENT_PLAN.md`](PROJECT_TOP_LEVEL_DEVELOPMENT_PLAN.md) —— 定义产品范围
3. [`TEAM_DEVELOPMENT_TASKS.md`](TEAM_DEVELOPMENT_TASKS.md) —— 定义交付顺序
4. [`06-灵档产品开发规划/`](06-灵档产品开发规划/) —— 定义灵档领域的详细设计

若第 4 项与前三项冲突，以前三项为准，并在第 4 项中同步修订。

## 阅读与实施约定

- 文档中的“应”“必须”是目标设计或验收约束，**不表示当前 WeKnora 已实现**。
- 任何跨域互动只走明确 API、命令或事件；禁止跨域直接写对方数据库表，或依赖 WeKnora 的短生命周期内部对象（如 chunk ID）。
- 优先验证一个完整的真实任务：固定资料集 → 章节草稿 → 一次研究条件变更 → 影响处置 → 人工确认 → 可编辑文件导出。
