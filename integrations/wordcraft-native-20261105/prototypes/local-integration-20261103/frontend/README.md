# LingDoc · 科研申报审阅工作台

设计基线：`LD-V1-20261103-R1`。

这是按最新前后端设计包实施的可点击前端，围绕《社区老年人数字公共服务使用障碍研究》串联“继续写作—处理导师意见—条件变化回看—复核交付”。旧四页结构、仿 Word 工具栏和 `contentEditable` 编辑器已移除。

## 运行

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
npm run preview
```

## 三条主空间

- **项目概览**：继续上次工作、当前意见、变化任务、正文依据与最新资料差异。
- **写作工作台**：真实 WordCraft 原生接入点、资料版本并排阅读、意见处理、显式 AI 上下文和建议对照。
- **审阅与交付**：人工意见与变化任务分开处理，记录决定和实际修改，查看覆盖范围、交付预览及可编辑路线图试验。

页头的 **S01—S10** 按钮可直接进入设计稿要求的十组交互状态。

## 重要产品规则

- 草稿生成、采用建议、保存、意见完成和导出是不同状态。
- 决定修改后仍为待处理；完成需要真实保存版本，或带理由的无需调整决定。
- 资料变化只提示检查，不自动修改正文、样本量、研究方法或图表。
- 历史研究快照仍指向当时的资料版本，不自动追随最新资料。
- AI 面板可添加、移除并展开实际请求上下文；未提供的内容不会被隐式读取。
- 资料与右侧辅助区独立开关；专注写作只隐藏外围区域。
- 原生定位未接入时只展示旧摘录，不使用文本搜索猜测位置。

## 当前能力边界

本交付是纯前端交互演示。所有业务修改仅存于当前页面，刷新后还原；没有连接真实 WordCraft、DS 文件宿主、Go 产品接口、模型服务或持久化。

原生区域使用设计包中的真实 WordCraft 运行截图作为明确标注的参考画面，不是当前申报稿，也不提供编辑、保存或导出。`src/lib/wordcraft-adapter.ts` 保留正式原生接入合同；`NativeHost` 可在提供 Adapter 时挂载真实宿主，演示环境没有提供实现。

保存失败、冲突、离线、发现更新等属于可点击的**状态分支演示**，不会发起真实写入。DOCX 打开与导出按钮会如实报告未接入，不生成假文件或假回执。

## 主要源码

- `src/data/scenario.ts`：统一虚构场景、任务状态和文案。
- `src/components/ProjectOverview.tsx`：项目恢复与任务队列。
- `src/components/WritingWorkspace.tsx`：写作任务、资料、意见与建议对照。
- `src/components/ContextAssistant.tsx`：实际可见上下文与演示会话。
- `src/components/NativeHost.tsx`：原生宿主接入点与参考占位。
- `src/components/ReviewDelivery.tsx`：变化回看、交付预览和路线图试验。
- `src/lib/wordcraft-adapter.ts`：正式原生适配合同。

接口对应与验收边界见根目录《LD-V1前端实施与接口映射.md》。
