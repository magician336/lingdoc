# Beta AI 辅助设计讨论

更新日期：2026-10-12。来源：grill-with-docs 访谈；关联 Wayfinder「确定下一条 G1–G7 开发切片」（issue #121）。

本文保存已确认决策和待确认边界，尚不是实施规格，也不表示所述能力已实现或验收。当前首版验收与完整 G1–G7 开发继续并行。

## 已确认决策

- 新增独立的当前任务助手，帮助科研用户理解状态、使用产品、处理待核事项和推进下一步；完整调研智能体也同时开始规划与开发，不因任务助手优先而延期。
- 关键状态变化时主动展示摘要卡片，不自动展开对话或执行动作；同时保留用户随时与 AI 对话的入口。
- 提示触发覆盖：项目创建/草稿字段变更，资料完成/失败/撤权/定位失效，AI 候选完成/失败/陈旧，章节待核/冲突/确认失效，ChangeSet 影响任务，模板检查/预检阻断，导出准备好/被阻断。
- AI 输出以结构化卡片呈现；用户可以引用卡片到对话中继续追问。
- 当前任务助手与调研智能体不共享原始会话，但共享可引用卡片和上下文包。
- 卡片由用户主动引用，或根据当前任务推测需要而引用；不能把所有卡片持续保存在模型上下文中。持久化保存卡片和每次请求是否纳入卡片是两个不同问题。
- 保持项目级上下文，每次请求显式固定使用范围；既有上下文设计继续作为依据，不另造平行语义。
- 卡片引用后的连续追问属于同一个 Agent 多轮对话。会话记录全部保留；每一轮按当前任务重新计算引用卡片、项目/对象版本和权限范围。切换任务后仍保留会话记录，但旧卡片正文必须重新鉴权和取用，不能直接沿用。
- 调研智能体的 ResearchTask/Run、来源卡片、ImportCandidate 和后续资料/证据对象之间预留交接接口；Beta 首轮同时启动调研智能体，不把完整研究证据链全部塞入同一轮交付。
- Agent 可以根据当前任务自动选择本轮需要的卡片和上下文，不要求用户逐张手工引用；系统必须显示本轮引用范围、选择理由和版本/权限状态。自动引用不能扩大授权范围，敏感资料或跨章节内容需要进入确认。
- Agent 可以执行保存研究条件、导入资料、创建 EvidenceCard、应用 ChangeSet、提交章节、确认和导出等业务动作；所有有副作用的动作先展示目标、输入范围、版本、权限和预期结果，由用户明确确认后执行。Agent 不得把确认藏在普通对话回复中。
- 用户确认的是 Agent 准备执行的业务动作及其范围，不需要重新手工拼上下文；创建 EvidenceCard、提交章节或确认记录只表示该业务动作已获授权，不表示系统或模型证明了学术结论正确。
- 业务动作按完整动作确认，不要求用户确认内部 API 步骤。读取、检索、整理、候选生成和状态刷新可自动执行；正式写入、权限扩大、删除、覆盖正式版本和关闭阻断问题不能自动执行。
- Agent 动作按可逆性处理：候选和工作副本可撤销/恢复；资料与证据对象保留历史并可停用或移出当前范围；ChangeSet 用反向 ChangeSet 恢复；提交/确认保留原记录并创建修订或重新确认；导出停止后续下载但不声称能撤回已下载的外部文件；失败和超时保留输入与运行记录，不重复写入或清空正文。
- 已确认完整调研智能体的首轮验收闭环：新想法 → 可编辑 ResearchTask → 用户确认范围 → 至少两轮检索 → 结果去重/分层/显示来源与不确定性 → 用户选片段 → ImportCandidate → 用户确认导入 → 项目资料可回看、可鉴权、可撤权；EvidenceCard、ResearchClaim、争议证据和多锚点 OCR 只预留交接接口。

## 既有上下文设计依据

- [用户界面与交互规划](09-用户界面与交互规划.md)：问答、生成或检查前显示项目、章节、资料、版本范围；对话与任务卡展示输出目标、依据和待确认项。
- [G7 正式章节编辑器与 AI 辅助写作](beta-gap-development-plans/G7-formal-chapter-editor-ai.md) §6.2：上下文包包含项目/章节/选区、业务版本、选定研究条件和资料/证据/主张、权限和模型原文访问许可、输出约束、模型及任务卡版本。默认使用当前章节与用户选定范围，项目可读不代表可以隐式读取全部项目正文。
- [调研智能体与知识沉淀规划](10-调研智能体与知识沉淀规划.md) §4、§7–8：草稿期和立项后共用调研能力；选定对话片段才能导入，运行固定项目和资料范围版本，新资料不静默混入正在运行的生成任务。

以上自动引用、业务动作确认、调研首轮闭环和恢复规则已在本次讨论中确认；后续只需把它们拆成实施任务和接口契约。
- 任务助手、调研、共享上下文/卡片基础能力及 G1–G7 消费方的子任务、主责和依赖。

先解决这些边界，再形成实施规格和并行任务票；不把此前尚未回答的 Q7/Q8 建议记为已同意。
